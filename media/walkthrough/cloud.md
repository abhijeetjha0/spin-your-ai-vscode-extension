# Cloud AI Setup
Unlock the most powerful frontier models directly in your editor.

By setting up your API keys, Spin Your AI securely stores them in your native operating system's keychain using VSCode's Vault Service.

- **OpenAI**: Access GPT-4o and o1 models.
- **Anthropic**: Access Claude 3.5 Sonnet.
- **Google**: Access Gemini 1.5 Pro.
- **OpenRouter**: Access dozens of hosted open-source and proprietary models.
- **Hugging Face**: Access serverless inference for HF Hub models.
- **Ollama Cloud**: Access Ollama's managed cloud models.
- **OpenCode**: Connect to an external OpenCode session.

Click the buttons to the left to configure your keys.
