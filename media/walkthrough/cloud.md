# Cloud AI Setup
Unlock the most powerful frontier models directly in your editor.

By setting up your API keys, Spin Your AI securely stores them in your native operating system's keychain using VSCode's Vault Service.

- **OpenAI**: Access GPT-4o and o1 models. [Set Key](command:spin-your-ai.setOpenAiKey)
- **Anthropic**: Access Claude 3.5 Sonnet. [Set Key](command:spin-your-ai.setAnthropicKey)
- **Google**: Access Gemini 1.5 Pro. [Set Key](command:spin-your-ai.setGeminiKey)
- **OpenRouter**: Access hundreds of hosted models. [Set Key](command:spin-your-ai.setOpenRouterKey)
- **Hugging Face**: Access serverless inference for HF Hub models. [Set Key](command:spin-your-ai.setHuggingFaceKey)
- **Ollama Cloud**: Access Ollama's managed cloud models. [Set Key](command:spin-your-ai.setOllamaCloudKey)

Click any link above or in the step description to configure your keys.
