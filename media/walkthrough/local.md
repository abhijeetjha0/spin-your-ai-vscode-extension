# Local AI Setup
Ollama is a popular local AI engine. If you have it running, Spin Your AI connects to it automatically!

1. Download and install [Ollama](https://ollama.com).
2. Run `ollama run llama3` in your terminal.
3. Open the Spin Your AI chat sidebar and start chatting for free!
